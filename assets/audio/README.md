# Default completion sound

`default-completion.mp3` is the user-supplied audio originally named
`a-new-message-has-arrived-on-facebook.mp3`, bundled at the user's request.
It is referenced relative to the plugin root so installations do not depend on
the original desktop file. The original file is retained unchanged.

The supplying user explicitly confirmed permission to publicly distribute this
audio with the project on 2026-09-05. The project's MIT code license does not
relicense this audio or imply permission for unrelated reuse. The sound can be
replaced or disabled in Settings.
